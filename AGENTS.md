# AGENTS.md — VVG ONLINE WebUI

## What this is

Blazor WebAssembly PWA for `vvgonline.net` — digital consulting site with AI chatbot (ONNX Runtime Web), Markdown blog, SEO meta, PWA offline, dark/light theme.

## Quick commands

| Action | Command |
|--------|---------|
| Run dev server | `dotnet run` (in `src/`, opens `http://localhost:5152`) |
| Run all tests | `dotnet test` (from root) |
| Publish release | `dotnet publish src/VVG.Web.csproj -c Release -o release` |
| Run tool (Indexer) | `dotnet run --project tools/Indexer` |
| Run tool (TwitterCardGenerator) | `dotnet run --project tools/TwitterCardGenerator` |

## SDK & build quirks

- **.NET 10** — `global.json` pins `10.0.100` with `rollForward: latestFeature`
- **Custom domain** — CNAME exists → `<base href="/">`. Without CNAME, CI rewrites to `/WebUI/`
- **Post-build gzip cleanup** — `scripts/remove-compressed-endpoints.py` is invoked by the `.csproj` after every build. The DevServer gzip substitution is buggy in .NET 10, returning 0 bytes for gzip framework assets.
- **`MetaTest.cs`** — excluded from compilation via `<Compile Remove>` in the `.csproj`
- **ONNX model** — tracked via Git LFS (`.gitattributes` has `*.onnx filter=lfs diff=lfs merge=lfs -text`)
- **`docs/`** — gitignored, generated by CI, deployed to GitHub Pages `gh-pages` branch

## Project structure

```
src/VVG.Web.csproj       # Blazor WASM app (net10.0)
tests/VVG.Web.Tests/     # xUnit + bunit + PuppeteerSharp
tools/Indexer/           # Blog index JSON generator (needs YamlDotNet)
tools/TwitterCardGenerator/ # SVG→PNG card generator (needs SkiaSharp, Svg.Skia)
scripts/                 # Post-build Python helpers
```

## App entrypoint & wiring

- `src/Program.cs` — DI setup, root components (`App`, `HeadOutlet`), MIME config for `.onnx`/`.json`, registers `MetadataService`, `ThemeService`, `CardImageService`
- Pages call `MetadataService.SetPageMetadata()` in `OnInitializedAsync()` to push SEO tags via JS interop → `meta.js`
- App boot: `App.razor` calls `JS.InvokeVoidAsync("vvg.initPage")` then `hidePreloader()` on first render

## Tests

- xUnit + bunit for component tests, PuppeteerSharp for integration (PWA offline, build tests)
- Tests reference `src/VVG.Web.csproj` directly
- Test categories: AssetValidation (7), Components (9), JSInterop (12), Integration (7), SEO

## Key services

| Service | File | Role |
|---------|------|------|
| `MetadataService` | `src/Services/MetadataService.cs` | SEO metadata from JSON files → JS interop |
| `ThemeService` | `src/Services/ThemeService.cs` | Dark/light theme persistence |
| `CardImageService` | `src/Services/CardImageService.cs` | Twitter card image URL resolution |

## CI/CD (`.github/workflows/deploy.yml`)

Trigger: push to `main`. Steps:
1. Checkout with LFS
2. `dotnet publish` → `release/`
3. Install fonts for TwitterCardGenerator (`apt install fonts-ebgaramond fonts-firacode fonts-ibm-plex`)
4. Run `tools/TwitterCardGenerator`
5. Fix `<base href>` if no CNAME
6. Generate `blog-index.json` via Node.js script (parses Markdown YAML frontmatter)
7. Generate static SEO HTML pages (SPA fallback with meta redirect)
8. Copy blog `.md` files to release
9. Create `.nojekyll`, `404.html`, `CNAME`
10. Deploy to `gh-pages` branch
